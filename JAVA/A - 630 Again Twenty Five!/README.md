<h2><a href="https://codeforces.com/problemset/problem/630/A">630A. Again Twenty Five!</a></h2><h3>Easy</h3><hr>

<p>The HR manager was disappointed again. The last applicant failed the interview the same way as 24 previous ones.</p>

<p>"Do I give such a hard task?" — the HR manager thought. "Just raise number <code>5</code> to the power of <code>n</code> and get last two digits of the number. Yes, of course, <code>n</code> can be rather big, and one cannot find the power using a calculator, but we need people who are able to think, not just follow the instructions."</p>

<p>Could you pass the interview in the machine vision company in IT City?</p>

<p>&nbsp;</p>

<h3>Input</h3>

<p>The only line of the input contains a single integer <code>n</code> (<code>2 &lt;= n &lt;= 2 * 10^18</code>) — the power in which you need to raise number <code>5</code>.</p>

<p>&nbsp;</p>

<h3>Output</h3>

<p>Output the last two digits of <code>5^n</code> without spaces between them.</p>

<p>&nbsp;</p>

<h3>Example</h3>

<div class="example-block">
<p><strong>Input:</strong></p>

<pre>
2
</pre>

<p><strong>Output:</strong></p>

<pre>
25
</pre>
</div>
